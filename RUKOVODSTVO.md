# Davomat — учёт прихода и ухода сотрудников

Система учёта рабочего времени на основе QR-кода. На проекторе или телевизоре
выводится QR-код, который обновляется каждые 30 секунд. Сотрудник сканирует его
камерой телефона и нажимает на своё имя — время прихода и ухода записывается
автоматически.

> **Примечание.** Интерфейс самой системы на узбекском языке. В этом руководстве
> названия разделов даются в оригинале, а рядом — перевод: «Bugun» (Сегодня).

---

## 1. Запуск

Дважды щёлкните по файлу **`ISHGA TUSHIRISH.bat`**.

В открывшемся чёрном окне появятся адреса:

```
============================================================
  DAVOMAT TIZIMI ishga tushdi
  Proyektor ekrani : http://192.168.x.x:8000/projector
  Admin panel      : http://192.168.x.x:8000/admin
============================================================
```

> ⚠️ **Не закрывайте это окно** — в нём работает сервер. Закроете — система остановится.

| Страница | Адрес | Кто открывает |
|---|---|---|
| Экран проектора | `/projector` | Офисный компьютер → проектор/ТВ |
| Панель администратора | `/admin` | Руководитель / отдел кадров |
| Страница сотрудника | автоматически по QR | Телефон сотрудника |

Начальный пароль администратора: **`admin`** — смените его при первом же входе
в разделе *Sozlamalar* (Настройки).

---

## 2. Первичная настройка (выполняется один раз)

1. Откройте `/admin`, пароль: `admin`
2. **Sozlamalar** (Настройки) → название компании, время начала рабочего дня
   (например `09:00`), допуск на опоздание (например `5` минут), новый пароль
3. **Xodimlar** (Сотрудники) → добавьте всех сотрудников
   (Ф.И.О. обязательно, остальное по желанию)
4. Кнопка **Proyektor** → выведите открывшуюся страницу на проектор и
   разверните на весь экран клавишей `F11`

---

## 3. Ежедневная работа

**Утром:** включается экран проектора. Сотрудник заходит → наводит камеру
телефона на QR-код → выбирает своё имя из списка → появляется приветствие
«Xush kelibsiz» (Добро пожаловать).

**Вечером:** сканирует тот же QR-код — теперь рядом с именем кнопка «Ketdim»
(Ухожу). Отработанное время считается автоматически.

**Руководитель:** `/admin` → раздел *Bugun* (Сегодня) показывает в реальном
времени, кто пришёл, кто опоздал, кого нет.

---

## 4. Зачем QR-код обновляется каждые 30 секунд

Адрес внутри QR-кода подписан секретным ключом и действует всего **90 секунд**.
То есть даже если сотрудник сфотографирует код и отправит коллеге, который
остался дома, это не сработает — код к тому моменту уже недействителен.

Кроме того, сервер работает **в локальной сети**: телефон обязан быть подключён
к офисному Wi-Fi. Отметиться из дома невозможно.

Сотрудники выбирают только имя (без PIN-кода), поэтому есть дополнительная
защита: если **с одного телефона** в течение часа отмечается несколько человек,
такие записи помечаются значком **⚠** в панели администратора. Порог меняется
в разделе *Sozlamalar* (Настройки).

---

## 5. Разделы панели администратора

### Bugun (Сегодня)
Табель за день: статус, время прихода и ухода, опоздание, отработанные часы.
- `← Oldingi` / `Keyingi →` (Предыдущий / Следующий) — переход по дням
- **Tahrirlash** (Редактировать) — ручная корректировка времени, например для
  сотрудника с разряженным телефоном. Если сохранить с пустым временем прихода —
  запись за этот день удаляется.
- **⚠** — с одного телефона отмечено много людей, стоит проверить
- **✎** — запись внесена вручную

### Hisobot (Отчёт)
Два представления за любой период:
- **Yig'ma** (Сводка) — по каждому сотруднику: сколько дней пришёл, опоздал,
  отсутствовал, суммарные минуты опозданий, общее отработанное время
- **Kunlik jadval** (Дневная таблица) — цветная сетка: зелёный — вовремя,
  жёлтый — опоздал, красный — не пришёл, синий — по уважительной причине

Кнопка `⬇ Excel` выгружает файл `.xlsx` из двух листов — для месячного отчёта
или расчёта зарплаты.

### Xodimlar (Сотрудники)
Добавление, редактирование, перевод в активные/неактивные.

> Уволившегося сотрудника **не удаляйте** — переведите в **nofaol**
> (неактивные). Удаление стирает и все его прошлые записи учёта.

### Yo'qliklar (Отсутствия)
Отпуск (*ta'til*), больничный (*kasal*), командировка (*komandirovka*), иная
причина (*sababli*). В указанные дни сотрудник отображается не как «не пришёл»,
а с выбранной причиной, и в отчёте считается отдельно.

## 6. Телефоны не подключаются?

Обычная причина — **брандмауэр Windows** блокирует порт 8000.

Откройте PowerShell **от имени администратора** и выполните один раз:

```powershell
New-NetFirewallRule -DisplayName "Davomat" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow -Profile Private
```

Что проверить ещё:
- Телефон и компьютер должны быть в **одной сети Wi-Fi**
- IP-адрес компьютера мог измениться. Возьмите адрес из чёрного окна и впишите
  его в поле *Sozlamalar → QR koddagi manzil* (Настройки → Адрес в QR-коде).
- На роутере должна быть отключена изоляция клиентов
  (Client isolation / AP isolation)

**Совет:** закрепите за компьютером постоянный IP на роутере (DHCP reservation) —
тогда адрес больше никогда не изменится.

---

## 7. Где хранятся данные

Всё в одном файле: **`data/davomat.db`**

Для резервной копии достаточно скопировать этот файл. Остановите сервер и
скопируйте папку `data` целиком — вместе с файлами `-wal` и `-shm`, лежащими
рядом с `davomat.db`.

Чтобы начать с нуля: остановите сервер и удалите файлы из папки `data` — при
следующем запуске будет создана пустая база.

---

## 8. Техническая информация

- Python 3.12 + FastAPI + SQLite, без зависимости от внешних сервисов
- Интернет не требуется, абонентской платы нет
- Переустановка библиотек при необходимости: `pip install -r requirements.txt`

Файлы:

```
app/main.py        — все страницы и логика
app/db.py          — схема базы данных
app/security.py    — подпись QR-токена (HMAC)
app/config.py      — часовой пояс, период обновления QR, статусы
app/templates/     — страницы
app/static/        — оформление
data/davomat.db    — база данных
```

Если позже понадобится вывести систему в интернет — код менять не нужно,
достаточно заменить *Sozlamalar → QR koddagi manzil* (Настройки → Адрес в
QR-коде) на внешний домен и поставить систему за HTTPS.
